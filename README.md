<span style="font-size: 17px; font-family: tahoma;"><strong>KnightLib</strong> is a multiloader utility library designed to eliminate code duplication and provide clean, easy-to-use implementations of systems that every mod tends to reinvent from scratch. Built on <a href="https://github.com/jaredlll08/MultiLoader-Template" target="_blank" rel="noopener">Jared's multiloader template</a>, fully compatible with <em>Forge</em>, <em>NeoForge</em>, and <em>Fabric</em>.</span>

---


## ☁️ What's included

| **System**                 |**Description**                                                                                                                     |
| ---------------------- |------------------------------------------------------------------------------------------------------------------------------- |
| 📡 <strong>Networking</strong> |Per mod S2C/C2S packet channels with a simple send/receive API                                                                  |
| ⚙️ <strong>Auto Config</strong> |TOML config with auto generated ingame GUI, hot-reload, and Configured/ModMenu (fabric) compatibility                           |
| ⚡ <strong>Event Bus</strong> |A common event system that abstracts the calls to their respective loaders, so that everything can be managed in common package |
| 🤖 <strong>Automaton AI</strong> |Finite state machine system for complex entity AI behavior                                                                      |
| 📦 <strong>OBB Hitboxes</strong> <em>(exp.)</em> |Oriented bounding boxes (OBBs) linked to individual GeckoLib bones, to manage hitboxes dynamically                              |
| 🎥 <strong>Camera Shake</strong> |<span class="HwtZe" lang="en"><span class="jCAhz ChMk0b"><span class="ryNqvb">API to manage camera shake for specific players, with several levels of configuration</span></span></span> |
| 👑 <strong>Boss Bars</strong> |Allows to specify and configure custom boss bars for the entities you want                                                      |
| 🎵 <strong>Music Provider</strong> |Loops music tracks for entities under custom conditions                                                                         |
| 🌀 <strong>Post Shaders</strong> |Utilities for post-processing shaders, including multi-target (entity) passes                                                   |
| 🌿 <strong>Biome Spawns</strong> |API for registering entity spawns per biome                                                                                     |
| 🎁 <strong>Loot Tables</strong> |Helpers for modifying loot tables in general (entities, chests, etc.)                                                           |
| 🔊 <strong>Persistent Sounds</strong> |Looping sounds tied to entities, items or blocks, <span class="HwtZe" lang="en"><span class="jCAhz ChMk0b"><span class="ryNqvb">without worrying about overlapping sounds</span></span></span> |
| 💾 <strong>Entity Data</strong> |API for quickly accessing the persistent data of an entity                                                                      |
| 📋 <strong>Registrar System</strong> |Enhanced registration helpers for blocks, items, entities and more                                                              |
| 🔢 <strong>Extra utilities&nbsp;</strong> |Additional utilities for math, colors, easingtypes, etc.                                                                        |
